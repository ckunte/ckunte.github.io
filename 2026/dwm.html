Omarchy reminded me of how much I love dwm, and I had this sudden urge to scavenge for an old Pi 3B+ (from 2016), and load it up with Pi OS lite + dwm on it. For its frugality1, I have a proper desktop — including greeter, screen lock, and some nice CLI tools. It’s glorious!2

The nostalgia of this interface was so nice that I set my daily driver to this interface last night, also to see if it holds-up better than the official Raspberry Pi OS Desktop. Obviously out of patience to write this install script line by line by myself — having tried before, I got Claude to create it. The script installs preferences and setup I like, following the essentials list.

  1. Rocking a 1GB RAM, 32G MicroSD card, and a Gigabit Ethernet. ↩

  2. I know it’s a cheeky screenshot in floating (than in tiling) mode in dwm just to feel the expanse of the desktop without a dock. ↩
